# Test Legko

Простой консольный скрипт для замера скорости интернета. Последовательно скачивает файл по заданному адресу 10 раз, считает среднее время запроса, объём данных и скорость в МБ/с.

## Требования

- Python 3.8+
- Внешние зависимости не нужны (только стандартная библиотека)

## Установка

```bash
git clone https://github.com/Yettolon/test_legko.git
cd test_legko
```

## Использование

```bash
python3 main.py <URL>
```

Пример:

```bash
python3 main.py https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
```

Параметры:

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `-n`, `--requests` | количество запросов | 10 |
| `-t`, `--timeout` | таймаут одного запроса, сек | 30 |

## Пример вывода

```
Цель: https://example.com/big.jpg
Запросов: 10

[ 1/10]   12.40 МБ за   1.95 с  ->   6.36 МБ/с
...
--- Итог ---
Успешных запросов:    10 из 10
Среднее время запроса: 1.90 с
Скачано всего:         124.00 МБ
Средняя скорость:      6.53 МБ/с (52.24 Мбит/с)
```

## Как считается

- Время каждого запроса - от отправки до полного получения тела ответа.
- Скорость = всего скачанных байт / суммарное время запросов.
- Запросы идут строго синхронно, сжатие и кэш отключены, чтобы замер был честным.
- Неудачные запросы пропускаются и не учитываются в среднем.

Для точного результата берите файл размером от нескольких МБ.
